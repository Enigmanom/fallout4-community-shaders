# Image Based Lighting

Rules, Kind legend and cross-cutting records: [README](README.md).

Consumed unchanged: `features/IBL/Shaders/IBL/DiffuseIBLCS.hlsl` (16x16 samples, two 3x1
`R16G16B16A16_FLOAT` SH textures), `IBL.hlsli` (apart from the fix in the Fix row), the IBL branch of
`Common/ShadowSampling.hlsli` and the IBL blocks of `DynamicCubemaps.hlsli` and the Exponential Height
Fog scattering shader. Not staged: `DiffuseIBL.dds` and `SpecIBL.dds`. The config key and short name
are `ImageBasedLighting`; code is `features\IBL`. Settings keys, defaults and ranges match the pin
(`PreserveFogLuminance` 0, `DALCAmount` 1 in 0-1, `EnvIBLScale` and `SkyIBLScale` 1 in
0-10, `EnvIBLSaturation` and `SkyIBLSaturation` 1 in 0-2, `FogAmount` 0 in 0-1, `DALCMode` 2 in 0-3,
`DisableInInteriors` and `DisableInLoadingScreen` on), except the omitted `UseStaticIBL` and
`DisableInWorldMap` below. The b6 `IBLSettings` block carries the upstream `PerFrame` layout; an
unpublished, disabled or unhealthy block reads `EnableIBL = 0`. Weather variables are upstream's set
without `EnableIBL` (`EnvIBLScale`, `SkyIBLScale`, `EnvIBLSaturation`, `SkyIBLSaturation`, `DALCAmount`,
`FogAmount`) as `[features.ImageBasedLighting.weather]` profiles, evaluated once per frame because b6
packs several times per frame. FO4-owned shader file: `package/Shaders/FO4/ImageBasedLightingConsumer.hlsli`.

Feature classification: **core** (rule 2). Pending rows remain unfinished and do not establish
upstream parity.
